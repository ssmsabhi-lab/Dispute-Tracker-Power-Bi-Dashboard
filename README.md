# Dispute Tracker Power BI Dashboard

## Overview
This Power BI dashboard is designed to monitor and analyze ATM dispute cases. It provides an interactive view of dispute status, KPIs, ownership, bank-wise analysis, and CRA performance.

## Features
- Dashboard for ATM dispute tracking
- Bank-wise analysis
- Ownership-wise analysis
- CRA-wise analysis
- Interactive filters
- KPI cards
- Drill-down reports

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Microsoft Excel

## Dashboard Insights
- Total dispute cases
- Pending vs Closed cases
- Bank-wise performance
- Ownership analysis
- CRA performance
- Dynamic filtering
